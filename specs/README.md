# Specs

Feature specs and task tracking for RSVP Manager, kept in-repo so history lives in git.

- [`feature-spec-mvp.md`](./feature-spec-mvp.md) — the MVP feature spec, decisions, and open questions.
- [`ui-ux-spec-mvp.md`](./ui-ux-spec-mvp.md) — MVP screens, sections, interactions and flows (no visual design).
- [`tasks.md`](./tasks.md) — implementation task tracker for the MVP.
- [`market-research.md`](./market-research.md) — competitors and alternatives, and where we differ.

New feature areas after MVP should get their own `feature-spec-<name>.md` file rather than growing this one indefinitely.
